PLASTECURE Documentation

Your guide to setting up and using the PLASTECURE system

1. Introduction

PLASTECURE is an innovative IoT-based project aimed at streamlining plastic waste management and recycling. It combines modern technologies such as ESP32 microcontrollers, Supabase databases, and user-friendly dashboards to enable efficient tracking and management of plastic recycling processes.

2. Features

  • IoT Integration: Monitors and tracks recycling activities in real-time using ESP32.
  • Supabase Database: Stores and manages recycling data securely.
  • User-Friendly Dashboard: Visualizes data and provides insights into recycling efforts.
  • Automation: Automatically logs recycling activity and tracks progress.
  • Eco-Friendly Focus: Promotes responsible plastic disposal and recycling practices.

3. System Overview

PLASTECURE consists of three main components:

  • Hardware (IoT Device):
    • ESP32 Microcontroller: The core of the system, managing sensors and communication.
    • Sensors: Collect data on plastic waste (e.g., weight or volume).
    • Actuators: Perform automated actions like sorting or bin management.
  • Backend:
    • Supabase: A cloud database that stores data like user activities, recycling logs, and system statuses.
    • Communication is established between the ESP32 and Supabase using APIs or MQTT.
  • Frontend:
    • Dashboard: A web-based interface where users can view data, monitor recycling statistics, and track progress.

4. How to Set Up

A. Hardware Setup

  1. Gather Components: ESP32 microcontroller, sensors, and power supply.
  2. Assembly: Connect sensors to the ESP32 as per the provided wiring diagram.
  3. Test Hardware: Verify that the sensors are functional by running a test program on the microcontroller.

B. Software Setup

  1. Flash the ESP32: Install the Arduino IDE or PlatformIO and load the firmware.
  2. Connect to Wi-Fi: Edit the WiFiConfig.h file with your Wi-Fi credentials.
  3. Link to Supabase: Ensure the ESP32 can communicate with the Supabase database by logging a test entry.

C. Dashboard Setup

  1. Access: Open the dashboard link in a browser.
  2. Log In: Use provided credentials.
  3. Customize: Set thresholds, notifications, or alerts as needed.

5. Troubleshooting

Issue Possible Cause Solution
Device not connecting to Wi-Fi Incorrect Wi-Fi credentials Recheck and update the WiFiConfig.h file
Data not updating in the dashboard ESP32-Supabase connection issue Verify Supabase API keys and network status
Sensor not responding Loose or incorrect wiring Check and reconnect sensor wires
